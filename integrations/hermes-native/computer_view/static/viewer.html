How control and session access work

Supported Hermes input is fenced while your human-control lease is active. Hand back explicitly when finished. Disconnect closes only this viewer; it does not silently return control or revoke other viewers.

Direct shell commands and same-user scripts are outside this boundary. This is not privacy isolation from other processes running as the same user.

To revoke all access, ask the owner to use the Computer View revoke tool in Hermes. This viewer cannot revoke all sessions. Session expiry and owner revocation are enforced by the server.

Pointer, touch, and physical keyboard input are handled by noVNC. Input tools are available only while this viewer holds control. Browser credential prompts are not supported; authentication must be configured by the owner.
