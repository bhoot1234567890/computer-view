# Changelog

## 0.1.0 — unreleased

- Portable owner-scoped HTTPS gateway for an existing private RFB Unix socket.
- Five-minute single-use links; thirty-minute sessions; live revocation.
- Private Telegram delivery, pinned noVNC assets, optional Cloudflare tunnel.
- Added fingerprint-pinned `browser-ca` check/import command; dry-run by default.
- Added egress allowlist, Chromium NSS certificate trust, container and browser restart troubleshooting.
- Allow-all domain policy is an explicit operator opt-in, never applied by the package.
- Added source packaging, security guidance, CI, and service examples.
